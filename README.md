🧮 Calculator Project

A simple and responsive calculator built using HTML, CSS, and JavaScript.
This calculator can perform basic arithmetic operations like:

Addition (+)
Subtraction (-)
Multiplication (×)
Division (÷)

It also includes:

Clear button (AC)
Delete button (DEL)
Decimal support
Responsive design
🚀 Features
Clean user interface
Button click functionality
Real-time input display
Evaluate expressions using JavaScript
Responsive layout for mobile and desktop
🛠️ Technologies Used
HTML
CSS
JavaScript
📂 Project Structure
calculator/

├── index.html

▶️ How to Run
Download or clone the project
Open the folder
Run index.html in your browser
💡 How It Works
Buttons are selected using querySelectorAll()
Click events are added using addEventListener()
Input values are displayed in the result field
eval() is used to calculate expressions
slice(0, -1) removes the last character for DEL button

Example:

inputField.value = eval(inputField.value);
